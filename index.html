桌面端专用
步骤 1 / 5

下载并安装 Codex

Codex 是 OpenAI 官方的 AI 编程助手，DeepSeek 已官方适配。请先下载并安装，然后至少启动一次（首次启动会生成本机配置目录 ~/.codex）。

提示：Windows 用户推荐从官方下载页下载（会跳转到微软商店）。安装完成后请打开一次 Codex，让它生成 ~/.codex 目录。
步骤 2 / 5

登录 DeepSeek 开放平台

点击下方按钮打开 DeepSeek 开放平台。如果没有账号，先在页面上注册；登录过程（密码、短信验证码）由你自己完成，工具不会接触你的密码。

步骤 3 / 5

创建并粘贴 API Key

在 DeepSeek 平台左侧进入「API Keys」，点击「创建密钥」。密钥只显示一次，复制后粘贴到下面的输入框。

以 sk- 开头；只在你的浏览器中处理，不会上传。

步骤 4 / 5

一键部署到 Codex

选一种方式把 DeepSeek 写进 Codex 配置。推荐方式 A：在浏览器里直接选择 ~/.codex 文件夹，自动写入并备份。

A. 网页一键部署

Chrome / Edge 浏览器支持，选择文件夹后自动写入配置并备份，可一键恢复。

B. 官方 PowerShell 脚本

复制命令到 PowerShell 运行，官方脚本会自动备份、校验、写入配置。

C. 手动下载配置文件

下载两个文件放到 ~/.codex 目录。已有配置时可先选择旧文件合并。

全部完成，开始使用

重启 Codex（CLI 或桌面 App），就会用 DeepSeek 模型开始工作。以后想切换模型或恢复配置，回到本页第 4 步即可。

使用小贴士

  • 切换模型：重新运行部署，选择 flash 或 pro 即可。
  • 恢复原配置：再次选择 ~/.codex 文件夹，点「恢复备份」。
  • 安全提醒：API Key 会以明文保存在 ~/.codex/config.toml，请不要分享该文件；如担心泄露，可在 DeepSeek 平台随时创建新 Key 并轮换。
  • 三端通用：配置一次后，Codex CLI、桌面 App、VS Code 插件共用同一份配置。
